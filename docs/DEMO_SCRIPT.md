# MinuteMark 66초 데모 녹화 대본

이 대본은 실제 공개 URL을 한 번 녹화하기 위한 순서다. AI 처리 시간은 환경에
따라 달라질 수 있으므로 분석 대기 구간은 편집해서 약 5초로 줄인다.

## 0–8초 — 문제와 입력

- 데스크톱 첫 화면을 보여준다.
- 내레이션: “MinuteMark는 회의에서 확정된 결정과 할 일을 근거 발화와 함께
  보여주는 AI 회의 노트입니다.”

## 8–18초 — 공개 샘플 선택

- `법안 통과 후속 작업`을 누른다.
- 처리 화면의 Whisper 전사와 Claude 구조화 문구를 보여준다.
- 실제 대기 시간은 짧게 편집한다.

## 18–36초 — 실제 AI 결과

- 타임스탬프 전사와 할 일 1개를 함께 보여준다.
- 처리 시간, 토큰, 예상 비용, `모든 근거 유효`를 차례로 가리킨다.
- 내레이션: “음성은 Whisper가 전사하고, 전사문만 Claude가 구조화합니다.”

## 36–48초 — 근거 듣기

- 할 일 카드의 `근거 듣기 · S5, S6`를 누른다.
- 오디오가 약 23.7초로 이동하고 전사 구간이 강조되는 장면을 보여준다.
- 내레이션: “AI 결과마다 실제 발화 근거로 즉시 이동할 수 있습니다.”

## 48–58초 — 비용과 신뢰성

- 예상 비용과 근거 검증 영역을 확대한다.
- 내레이션: “출력은 서버에서 다시 검증하며, 판매자의 구조화 출력이 실패하면
  일반 JSON 폴백 후 같은 검증을 통과해야만 표시합니다.”

## 58–66초 — 모바일과 마무리

- 390px 모바일 화면으로 전환한다.
- 내레이션: “Docker 이미지 하나로 Cloud Run에 배포했고, 공개 샘플로 바로
  확인할 수 있습니다.”
- 공개 URL을 2초간 보여준다.

## 녹화 체크

- API 키, 브라우저 계정, Cloud Console 탭이 화면에 나오지 않게 한다.
- 실제 분석 결과와 비용 수치를 사용한다.
- 대기 시간만 줄이고 결과 화면은 합성하지 않는다.
- 파일 업로드 QA가 통과하기 전에는 업로드 장면을 데모에 넣지 않는다.
