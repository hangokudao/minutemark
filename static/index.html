개인정보처리방침

포트폴리오 데모입니다. 실제 업무·기밀·민감정보가 포함된 파일을 업로드하지 마세요. 업로더는 녹음·분석에 필요한 참여자 고지와 권한을 확보해야 합니다. 전사문은 결과 생성을 위해 A6API로 전송됩니다. 포트폴리오 운영자는 회의 분석·저장 기능 제공을 위해 아래와 같이 개인정보를 처리합니다. 개인정보 보호 담당은 ‘MinuteMark 개인정보 보호 담당’이며, 문의는 hangokudao@gmail.com으로 받을 수 있습니다.

처리하는 정보와 목적

  • Google 로그인: Firebase UID, 이메일, 로그인·가입 시각 — 사용자 인증과 회의 소유권 확인
  • 회의 분석: 사용자가 올린 음성, 전사문, 회의 제목, 결정·할 일 — 분석 결과 제공과 재열람
  • 기술 정보: 오류 시각과 요청 상태 — 장애 확인. ID token, 이메일, 전사문, signed URL은 앱 로그에 남기지 않음

처리 흐름과 보관

음성은 Google Cloud 서울 리전의 비공개 Storage에, 결과는 Firestore 서울 리전에 저장됩니다. 서버의 faster-whisper가 음성을 전사하며 원본 음성은 A6API에 보내지 않습니다. 전사문과 구간 ID·시각만 A6API의 GPT-5.6 Luna 모델에 보내 결정과 할 일을 구조화합니다.

회원이 회의를 삭제하거나 계정을 탈퇴할 때까지 보관합니다. 회의 삭제 시 원본 오디오와 결과를 즉시 삭제하며, 이 전용 버킷의 soft delete와 객체 버전 관리는 사용하지 않습니다.

Firebase SDK는 로그인 상태를 브라우저의 로컬 저장소에 유지합니다. 로그아웃하거나 계정을 탈퇴하면 앱의 로그인 상태가 해제되며, 브라우저 설정에서 사이트 데이터를 직접 지울 수도 있습니다.

외부 서비스와 국외 처리

  • Google Firebase Authentication — 로그인과 계정 식별
  • Google Cloud Firestore·Storage — 서울 리전 결과·오디오 보관
  • A6API를 통한 GPT-5.6 Luna — 전사문에서 결정·할 일 추출. 제공자의 보관·학습·처리 위치는 확인되는 범위 밖에서 단정하지 않음

삭제와 이용자 권리

회의 상세의 ‘회의 삭제’ 또는 계정 화면의 ‘회의와 계정 모두 삭제’로 직접 삭제할 수 있습니다. 계정 탈퇴 전에는 Google 재인증을 요구합니다. 처리 정보의 열람·삭제 문의도 위 이메일로 요청할 수 있습니다.
